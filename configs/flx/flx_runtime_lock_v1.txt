# flx_cpu_linux_x86_64_v1 — the exact runtime, pinned by bytes.
#
# Stage 8A recorded DEPENDENCY_VERSIONS_NOT_LOCKED against this artifact,
# because upstream's requirements.txt names packages without versions. This
# file is the answer: every distribution that ends up importable inside the
# worker, at one exact version, as one exact wheel, with that wheel's SHA-256.
#
# It is simultaneously a machine-readable manifest and valid pip input:
#
#     pip install --require-hashes --no-deps -r configs/flx/flx_runtime_lock_v1.txt
#
# --require-hashes makes pip refuse anything whose bytes differ, and --no-deps
# with the full transitive closure listed means pip resolves nothing at install
# time. The `# <filename>` / `#   size:` / `#   index:` comments above each pin
# are read by fpbench.flx.lock and ignored by pip.
#
# This file's own SHA-256 is part of the runtime manifest, and therefore part
# of every representation's identity. Editing it — even to a version already
# installed — is a different runtime.
#
# Torch and torchvision come from PyTorch's CPU index, not from PyPI. The PyPI
# wheels of the same version pull the CUDA runtime, which would put several
# gigabytes of GPU libraries into a profile that has no device and must not
# acquire one (docs/adr/0072).
#
# Regenerate with:
#     python integrations/flx/runtime/build_runtime.py lock
